Keyforge

Generate an ed25519 holder identity, and sign or verify a real CADS-agent-marketplace ServiceManifest — entirely in your browser, in WebAssembly. Your private key is generated on this page and never sent anywhere.

Step 1

Your holder identity

How this works

Generated with ct-agent-wasm's generate_holder_identity() — the same production-proven ed25519 keypair generator a real ct-agent uses for its channel identity.

Public key (hex)
Private key (hex) — held only in this tab's memory
Security details
The private key never leaves this page: it is generated by WebAssembly running locally and used only for the local signManifest/holderSign calls below. Nothing here makes a network request that includes it. Reload the page and it is gone — this is a demo identity, not a place to keep a real one.
Step 2

Verify a real manifest

How this works

Fetches a live, publisher-signed manifest from registry.bunsenbrenner.org and checks its ed25519 signature — entirely client-side, via manifest-core-wasm calling ServiceManifest::is_valid directly (no preimage logic reimplemented in JS). A valid signature only binds the manifest to the key it names, so the page also says whether the live registry lists that key.

Step 3

Sign your own manifest

How this works

Edit the template below (or generate a fresh one), then sign it with your holder identity from Step 1 via manifest-core-wasm's signManifest — this calls ServiceManifest::sign_new directly, so publisher_pubkey is always derived from your own key.
